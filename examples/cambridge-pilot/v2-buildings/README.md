# Cambridge loops with portable buildings

Download `brookmount-clockwise.json` (330 buildings) or `brookmount-anticlockwise.json` (324 buildings), then import it into the updated development simulator. The pilot load buttons select this revision automatically. Existing saved revisions are retained.

Buildings use the simulator facade palette and are included in the JSON. Their positions and sizes are synthetic scenery, not surveyed OSM or Mapillary footprints. Both routes retain the original road geometry, distance and provisional spawn. The neighbouring v1 files are kept for history.

Use the updated simulator for restored waypoint-related road paint and ungraded practice. An old build can display these buildings but will still ignore experimental mode. See [setup and evidence](../../../docs/CAMBRIDGE-PRACTICE-LOOPS.md).
