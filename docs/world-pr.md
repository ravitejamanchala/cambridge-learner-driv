# Cambridge data pipeline and source inspector (data gate pending)

The existing simulator loads authored areas and personal-route geometry but has no validated, complete Cambridge city dataset. This branch adds a reproducible data-stage pipeline and a connected source-geometry inspector before any broad renderer changes.

- Confirmed base: main at e4449195fc27e38d010c335ba256b5969fcffed0.
- Boundary discovery, pinned/resumable OSM requests, raw checksums, normalization with provenance/holes/unknown dimensions, source-node topology/restrictions, complete declared tile inventory, immutable outputs and explicit coverage/rejection reports.
- North-up browser inspector with source selection, layer/tile controls, failure recovery and checksum verification. Preview builds include world-inspector.html; production builds exclude it.
- Original synthetic fixture and source/asset/geographic audits. No Roadarium application or assets are bundled.

**Not ready for production:** live boundary/source acquisition and Google satellite access are blocked by the environment proxy (403/tunnel failure). The full Cambridge dataset, accepted geographic audit, continuous city driving, terrain and asset refinements are not complete. Generated datasets remain accepted:false. Do not merge this as the completed city renderer.

Validation: 261 unit tests passed (including 16 new pipeline checks); production/preview/inspector builds passed; inspector browser interactions and existing personal-route/graded-mock/mobile regression passed. Evidence and exact commands: docs/world-validation.md and docs/evidence/world/.

Learner progress, grading, car assets and production deployment behavior are unchanged. This is a developer diagnostic stage: no learner rewards, marks or outcomes are generated by the inspector. Production/main is not pushed or deployed by this work.
