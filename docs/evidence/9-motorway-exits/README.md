# Leaving the motorway, and missing your exit (issue #9)

Recorded with `node tools/record_evidence.mjs exits` on 2026-10-24: the real application,
stepped at 20 frames a second and captured frame by frame, so each clip plays at true speed unless it says otherwise.
The careful drives use the Bot lab's reference driver (`js/bots.js`); the careless ones use the scriptable driver from `npm run test:motorway` (`tests/mw-driver.mjs`), making the same mistakes the checks make.
