# Steering a person can manage, and leaving the road marked

Recorded with `node tools/record_evidence.mjs handling` on 2026-10-24: the real application,
stepped at 20 frames a second and captured frame by frame, so each clip plays at true speed unless it says otherwise.
The "person on keys" is the Bot lab's human-like driver: the reference driver's intentions seen 0.3 s late, decided ten times a second, on/off keys tapped, and steering no firmer than that reaction time allows. The lessons were chosen before recording (the simplest town turn and the simplest motorway lesson), not picked for the result. The "old steering" clips are the same build with only the old steering mapping put back (`BEFORE_URL`).
